# English Speech Coach

Прототип iOS-приложения для практики разговорного английского. Пользователь выбирает режим, отвечает на ситуативное задание и получает обратную связь по ответу и статистику попыток.

Проект написан на SwiftUI. Текущий экран ответа использует редактируемый текст вместо настоящего распознавания речи.

Откройте `SpeechCoachApp.xcodeproj` в Xcode и запустите схему `SpeechCoachApp`.
