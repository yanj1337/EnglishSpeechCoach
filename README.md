# English Speech Coach

SwiftUI-прототип iOS-приложения для практики разговорного английского. Главное окно открывает пример тренировки: вспомнить фразу, посмотреть ответ и самостоятельно отметить результат. Оформление основано на предоставленных референсах.

Это демонстрация экранов с одной примерной фразой, а не готовая система карточек или статистики. Микрофон, распознавание речи и оценка произношения не используются. Существующий код модели оставлен для дальнейшей работы и не управляет демонстрацией.

## Запуск

Нужен Xcode с поддержкой Swift 6. Откройте `SpeechCoachApp.xcodeproj`, выберите схему `SpeechCoachApp` и запустите приложение на iOS 17 или новее.

## Структура проекта

- `iOS/` — приложение и интерфейс SwiftUI.
- `Sources/SpeechCoachCore/` — модели и логика тренировок.
- `Tests/SpeechCoachCoreTests/` — тесты модуля `SpeechCoachCore`.
- `TECHNICAL_RESEARCH.md` — заметки о технических вариантах распознавания речи.
